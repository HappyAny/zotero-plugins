# DOI Fix 1.2.1 本地增强

在“获取 DOI”或“更新 DOI”后，预印本条目会继续检查正式出版信息。Crossref 返回同一 DOI、标题匹配且出版类型为期刊论文、会议论文或书籍章节时，插件会原地更新条目类型、作者、期刊、会议录或书名、出版日期及已登记的卷期页码。

已经补好正式 DOI、但仍为预印本的条目也适用：再次执行“获取 DOI”或“更新 DOI”即可完成转换。已是正式版的条目不会因此重复查询。

转换保留原条目 ID 和 key、PDF 附件及其批注、笔记、标签、分类，以及 Extra 中的评分和阅读状态。arXiv 编号会保存在 Extra；转换前的出版字段和类型专属字段另存为 `DOI Fix preprint metadata` 记录。原摘要和引用键不由该功能改写。

网络请求失败、返回预印本 DOI、缺少正式出版记录、标题不匹配，或查询期间条目被编辑时，不执行转换。已获取的 DOI 仍保留。功能只在执行获取或更新命令时运行，不增加定时扫描。

这是基于上游 1.1.9 的本地增强，保留上游 MIT 许可证，尚未发布到上游。

源码发布前的独立审查补充了三处保护：获取或更新 DOI 时拒绝未保存编辑，查询期间条目变化时停止写入；按不同词计算标题重合；比较 DOI 时忽略大小写并保留原有写法。相关命令级回归已加入现有测试。

## 验证

新增测试使用 Crossref 实际返回的 `10.1103/jwmx-j2pg` 元数据，并覆盖会议论文转换、原有 DOI、缺失字段、保留附件和阅读数据、并发请求、查询期间编辑、网络失败及保存回滚。精简验证记录保存在 `../docs`。跨平台构建脚本和隔离测试准备脚本保存在 `../scripts`，不依赖个人配置、数据库或旧安装包。
